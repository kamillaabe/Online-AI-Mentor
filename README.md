## Online AI Mentor — сайт (шаблон)

Это простой статический сайт про онлайн ИИ‑ментора для участников программы **FIRST**.

Мы создали этот проект с целью **решить проблему ограниченного доступа к качественному наставничеству в сельских местностях**: когда рядом нет кружков/менторов, онлайн‑формат помогает учиться и готовиться стабильно.

### Как открыть

- Откройте файл `index.html` двойным кликом (в браузере).
- Или запустите любой локальный сервер (не обязательно).

### Что можно легко поменять

- Тексты и контакты: блок **Контакты** в `index.html`
- Цвета и стиль: `styles.css`
